# ModularGameOverlay

ModularGameOverlay yhdistää SuperLighterin, Aimoron ja
SoundDirectionVisualizerin yhdeksi Windows-overlay-apusovellukseksi.

Projekti on tällä hetkellä suunnittelu- ja perustamisvaiheessa. Toteutuksen
sitova tavoite, rajaus, vaiheistus ja hyväksymiskriteerit on kuvattu
dokumentissa [docs/TAVOITE-JA-SUUNNITELMA.md](docs/TAVOITE-JA-SUUNNITELMA.md).

Kaikkien projektiin osallistuvien ihmisten ja agenttien on luettava
[AGENTS.md](AGENTS.md) ennen muutosten tekemistä. Projektin dokumentaatio ja
testit ovat ylläpidettävä osa toteutusta, eivät jälkikäteen tehtävä lisä.
